# little_maia2

A lightweight model for probabilistic chess move prediction, focused on lower-rated players (≤ 1200 Elo). Fork/derivative of [CSSLab/maia2](https://github.com/CSSLab/maia2).

## Agent skills

### Issue tracker

Issues live as GitHub issues on `DeyonOba/little_maia2`, operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`) use their default names; no remapping. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
